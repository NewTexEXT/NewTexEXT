## ¿Qué hacemos?

Somos una consultora tecnológica especializada en construir soluciones a medida para PYMEs y empresas industriales. No vendemos software genérico — diseñamos arquitecturas que resuelven cuellos de botella operativos reales y generan retorno de inversión demostrable desde el primer día.

| Área | Qué construimos |
| :--- | :--- |
| 🤖 **Agentes virtuales** | Chatbots IA para WhatsApp y web (plataforma propia NTX-Agent) |
| 📞 **Asistentes de llamadas IA** | Atención telefónica por voz con IA (Retell AI + ElevenLabs + Twilio) |
| 📄 **Documentos con IA** | Extracción y generación automática de documentos (DOCTUM) |
| 📅 **Reservas y citas** | Gestión de citas sin comisiones por cliente captado (CITARA) |
| 📦 **Control de stock** | Trazabilidad en tiempo real para talleres y fábricas (TRAZZA) |
| ⚙️ **Automatización de procesos** | Eliminación de trabajo manual repetitivo en flujos de negocio |
| 🔗 **Integración de sistemas** | APIs, CRMs, ERPs, flujos de datos entre plataformas |
| 🌐 **Web y apps a medida** | Portales, motores de reservas, apps móviles nativas iOS/Android |
| 🔍 **Consultoría tecnológica** | Auditoría de procesos e implementación de soluciones |

## Productos propios en producción

Software escalable que diseñamos, desplegamos y mantenemos en nuestra propia infraestructura.

**🤖 NTX-Agent** — Plataforma SaaS multi-tenant de agentes virtuales e IA conversacional sobre WhatsApp Business. Arquitectura multi-tenant con vinculación de dispositivos.
<br>[![Ver en vivo](https://img.shields.io/badge/Ver_en_vivo-ntx--agent.newtex.es-F2B705?style=flat-square&logoColor=0D0D0D)](https://ntx-agent.newtex.es)

**📦 TRAZZA** — Control y trazabilidad de stock en tiempo real. Orientado a talleres, pequeñas fábricas y empresas con gestión de inventario compleja.
<br>[![Ver en vivo](https://img.shields.io/badge/Ver_en_vivo-trazza.newtex.es-F2B705?style=flat-square&logoColor=0D0D0D)](https://trazza.newtex.es)

**📄 DOCTUM** — Extracción y generación de documentos con IA. Lee facturas y documentos, extrae los campos definidos y genera PDFs desde plantillas.
<br>[![Ver en vivo](https://img.shields.io/badge/Ver_en_vivo-doctum.newtex.es-F2B705?style=flat-square&logoColor=0D0D0D)](https://doctum.newtex.es)

**📅 CITARA** — Gestión de reservas y citas con recordatorios por WhatsApp, sin comisiones por cliente. Para cualquier negocio de cita previa.
<br>[![Ver en vivo](https://img.shields.io/badge/Ver_en_vivo-citara.newtex.es-F2B705?style=flat-square&logoColor=0D0D0D)](https://citara.newtex.es)
